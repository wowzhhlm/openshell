# openshell 2.2

开源、轻量、无需注册且无有效期的**多协议终端客户端 + 网络拓扑配置工具**。

`openshell 2.2` 是合并后的唯一正式版本，替代此前的 v1.4.x、OpenShell 网络版 v2.0.0 与 v2.1；旧版本项目文件均已清理。源码与生成结果统一位于 `D:\openshell\`，GitHub 仓库为 `wowzhhlm/openshell`。本项目为从零实现的干净房间（clean-room）客户端，不使用 Xshell / SecureCRT 的代码、签名、品牌资源或任何专有组件。

**v2.2 命名变更**：分发包由「openshell 便携版」改名为 **「openshell 免安装」**（目录 `openshell-2.2-免安装`、压缩包 `openshell-2.2-免安装.zip`），程序内的「便携模式」统一改称「免安装模式」。

## 核心功能

### 1. 九种协议终端
- **SSH**：多标签终端（xterm.js 渲染，密码 / 私钥认证、窗口自适应、主机密钥校验）
- **Telnet**：明文远程登录，可选自动登录
- **RLOGIN**：明文远程登录（RFC 1258，端口 513），**终端速度可配**（默认 38400，写入登录首包）
- **SFTP**：加密文件传输（独立模式 + 侧边面板，上传 / 下载 / 删除）
- **FTP**：传统文件传输（端口 21，被动模式，列目录 / 上传 / 下载 / 删除）
- **RDP**：Windows 远程桌面图形协议，按会话参数生成 `.rdp` 配置后一键调用系统"远程桌面连接"
- **Serial 串口**：基于 Web Serial API，**端口号 / 波特率 / 数据位 / 停止位 / 奇偶校验 / 流控制均可配**
- **Local 本地终端**：在本机启动系统 Shell（Windows cmd）
- **Raw 原始 TCP**：裸连接字符透传

### 2. 主密码保险库（密码导出 / 导入）
- 导出 OpenShell JSON 时**默认导出密码**：先验证工具主密码，再用主密码（`scrypt` 派生密钥 + `AES-256-GCM` 认证加密）把密码字典加密进会话文件。
- **仅当两台电脑主密码相同**时，导入才能还原密码——加密数据自带随机 salt，不依赖本机状态。
- **清除密码选项**：导出区域提供"导出密码（用主密码加密）"复选框，可取消勾选以不导出任何密码，用户自主选择。
- 主密码仅在本地保存校验串（同样加密），不明文存储、无法找回。
- 第三方格式（Xshell / SecureCRT）为私有加密，仍不写入密码。

### 3. Linux 命令中文查询（调试辅助 · 非模态浮动面板）
- 内置 69 条常用命令，涵盖文件目录、文件内容、系统监控、网络、权限、进程服务、压缩归档、文本处理等分类。
- 每条含：功能说明、语法、常用参数、实测示例。支持按命令名 / 功能 / 分类 / 参数离线搜索。
- **为「边查命令边敲终端」设计**：查询窗口是**非模态浮动面板**，没有全屏遮罩、不拦截终端点击，可拖到屏幕任意位置；因此调试时可以一边看说明一边在终端输入，不必先关窗口。
  - 按住标题栏拖动、右下角拖动缩放、双击标题栏复位到默认位置；
  - 标题栏 `—` 收起为一条标题（完全不遮挡终端）、`◐` 半透明模式（鼠标移入自动恢复清晰）、`×` 关闭；
  - 位置 / 尺寸 / 收起 / 半透明状态写入 localStorage，下次启动保持，方便固定在常用角落；
  - **点击命令名或示例**即可复制到剪贴板；每张卡片还有「发送到终端」，把命令送到当前终端光标处（**不自动执行**，确认后回车），避免复制粘贴来回切换。
  - 再次点击顶部「📖 Linux 命令查询」可收起 / 展开面板（收起态会先展开）。

### 4. 网络拓扑与交换机配置自动生成
- **自定义绘制拓扑**：拖拽交换机 / 路由器 / 终端等设备安装、连线、配置接口 / VLAN / IP。
- **自动生成配置**：根据拓扑批量生成多品牌 CLI 命令，支持 **华为（VRP）、思科（IOS）、H3C（Comware）、锐捷、TP-LINK**；覆盖 VLAN、Trunk、VLANIF、静态路由等场景。
- **智能化增强（本项目自研，见 `src/topology/js/smart-config.js`）**：
  - 🩺 **配置体检**：IP / VLAN 冲突检测、网关跨网段、网络号与广播地址误用、孤立设备、未选厂商等，输出评分与逐条修复建议；
  - 🌐 **自动 IP / VLAN 规划**：按 VLAN 分配 `10.<site>.<vlan>.0/24`，网关 `.1`、设备从 `.10` 起，不覆盖已填地址，可一键回填画布；
  - 📖 **命令逐行中文解释**：内置华为 / 思科 / H3C 规则库，生成"命令 → 说明"阅读版；
  - 🗂 **批量导出**：把批量命令拆成每台设备独立 `.cfg` 脚本 + 合并配置包 + 清单，统一保存到 `D:\openshell\导出\配置包_<时间>\`；
  - ⚡ **批量生成前置体检**：生成命令时自动在终端输出顶部插入体检摘要，可开关"逐行解释"。
- **一键下发**：通过已有 SSH 会话，把配置自动下发到交换机并保存（工具菜单"下发配置到交换机"）。
- 拓扑引擎基于开源项目 `bobhe2016/net-topo-cmd-generator-web`，G6 已本地化，离线可用。
- ⚠️ **合规提示**：该上游仓库 README 声称 MIT，但 GitHub API `license: null` 且无 LICENSE 文件，授权状态待确认；已移除其随附的混淆加载器与第三方收款内容。详见 `src/topology/THIRD_PARTY_NOTICES.md` 与 `报告\拓扑引擎评估与升级方案.md`。

### 5. 会话管理与通用能力
- 分组、搜索、右键编辑 / 复制 / 删除；顶部全中文菜单（文件 / 编辑 / 会话 / 工具 / 视图 / 帮助）。
- **所有弹窗可拖动**：新建会话、设置、主密码、密码输入等模态框均可按住标题栏拖动（限制在窗口内、双击标题栏复位），不再固定居中挡住内容。
- **会话列表断开连接按钮**：每个会话行在「连接 / 编辑」之外新增「断开」按钮，右键菜单也有「断开连接」。按钮按连接状态实时联动——无连接时置灰、有活动连接时启用且该会话常显操作按钮并带绿色连接指示点；断开只清理连接资源、把标签标记为 `closed` 并写入一行 `[已断开]`，**保留标签与历史输出**，可再次连接或右键「重新连接」。
- **一级直达菜单**：「🌐 网络拓扑与配置生成」「📖 Linux 命令查询」从工具子菜单移出，作为顶部一级按钮，点击直达、无需展开子菜单。
- **首次连接凭据流程**：导入的会话不含密码，第一次连接时先弹「输入连接密码 / 私钥口令」（带 👁 明文切换），确认后再询问「是否保存密码」，最后才开始握手；保存的凭据由系统加密，不写入会话文件；选择不保存则仅本次临时使用。
- 批量导入 / 导出（多文件、目录递归，最多 500 个文件 / 单个 2MB）。
- **跨客户端迁移**：
  - 可直接导入：Xshell `.xsh`（INI/XML）、SecureCRT `.ini`、OpenShell JSON、**CSV / TSV 表格**（支持中英文表头、乱序列、引号字段、BOM、分号分隔、Xshell 固定列顺序）。
  - **`.xts` 加密归档自动兜底**：`.xts` 是 Xshell 用主密码加密的专有归档，无法离线解密。当前版本不再直接报「未解析出有效会话」，而是：
    ① 先嗅探内容，若确为明文 INI/XML/JSON/CSV 仍正常解析；
    ② 确认加密后，自动扫描本机 `文档\NetSarang Computer\<版本>\Xshell\Sessions\*.xsh` 并导入同一批会话；
    ③ 也可用「文件 → 从本机 Xshell 会话导入…」主动导入，或在引导弹窗里手动选择 Sessions 目录；
    ④ 兜底失败时给出清晰的替代方案（Xshell 导出 CSV / 另存为 `.xsh` / 取消主密码重新导出）。
  - CSV / TSV 中的明文密码出于安全考虑不自动写入凭据，会给出提示。
- 端口转发、脚本发送、多主题（深空蓝默认 / 浅色 / Solarized）、字体与回滚行数可调。
- **输入框右键菜单**：新建会话等表单里可正常「撤销 / 剪切 / 复制 / 粘贴 / 全选」；终端内右键为自定义菜单（复制选中 / 粘贴 / 全选 / 清空 / 重新连接），快捷键 `Ctrl+Shift+C/V/A`。
- **密码框查看按钮**：密码与私钥口令输入框右侧 👁 按钮可切换明文 / 星号，方便核对。
- **连接原标签重试**：连接失败后标签保留并显示原因，再次连接同一会话或右键「重新连接」会**在原标签追加「第 N 次连接尝试」分隔线并完整保留历史错误信息**，不清屏、不另开新标签。
- **SSH 算法兼容**：算法列表放在 ssh2 要求的 `cfg.algorithms`（此前误放在 cfg 顶层导致修复无效），覆盖 `diffie-hellman-group14-sha1` / `aes128-cbc` / `ssh-rsa` / `hmac-sha1` 等旧算法，解决 `no matching key exchange algorithm` 握手失败；已用「默认算法必失败 / 修复算法必成功」的对照组实测验证。
- 导出位置自选（系统目录选择对话框）。

### 6. 会话高级参数（v2.2 新增，参照 Xshell 同类设置）

新建 / 编辑会话弹窗改为六个标签页：**常规 / 串口 / RLOGIN / RDP / 保持活动 / 日志**。参数随会话保存、随 OpenShell JSON 导入导出往返，也可从 Xshell `.xsh` 文件尽力还原；所有值在 `session-format.js` 的 `optionDefaults()` 与主进程中做类型与范围校验。

- **串口**：端口号（COM1…COM20，可手输）、波特率（300～921600）、数据位（5/6/7/8）、停止位（1/2）、奇偶校验（无 / 偶 / 奇 / 标记 / 空格）、流控制（无 / 硬件 RTS-CTS / 软件 XON-XOFF）。Web Serial 标准仅支持 7/8 数据位、none/even/odd 校验与 none/hardware 流控制，不受支持的组合按最接近有效值打开并在终端提示。
- **RLOGIN**：终端速度（300～115200，默认 38400），写入 RFC 1258 登录首包 speed 字段。
- **RDP**：窗口大小（Work Space 当前工作区 / 全屏 / 自定义宽高）、智能重新连接、屏幕缩放、颜色质量（32/24/16/15 bit）、在远程计算机上应用密钥组合、共享本机驱动器、远程音频播放（不播放 / 本地 / 远程）、从这台电脑录制、使用 Windows 身份验证。参数写入 `配置\rdp-*.rdp` 后交给系统 `mstsc`，**不写入明文密码**。
- **保持活动状态**（SSH / Telnet / RLOGIN / Raw / FTP）：
  - 连接会话期间发送保持活动状态消息（间隔秒数，默认 60 秒；SSH 用协议层 `keepaliveInterval`，取消勾选则设为 0 禁用）；
  - 网络空闲时发送字符串（间隔秒数 + 自定义字符串，支持 `\n` / `\r` / `\t` 转义；数据到达时间由主进程 `send()` 统一刷新）；
  - 网络为空闲状态时发送 TCP 保持活动数据包（`SO_KEEPALIVE`；Telnet/RLOGIN/Raw 用公开 API，SSH 在 `ready` 后设置底层 socket，默认路径完全不变）。
- **连接日志**：按会话启用，支持追加到已有日志 / 每次连接新建文件、每行时间戳、可选记录键盘输入；「设置」里可开启「新建会话默认启用连接日志」。日志覆盖终端输出、连接进度、状态、错误与端口转发记录，串口（Web Serial）数据由渲染层经 `log:write` 汇入同一个写入器，ANSI 转义会被剥离、按行缓冲写入。文件位于 `日志\`，「文件 → 打开会话日志目录」可直接打开。

> 日志会记录终端输出，远程回显的敏感内容无法过滤；「记录键盘输入」默认关闭，请谨慎开启并妥善保管日志文件。

## 安全设计

- **最小权限渲染进程**：`contextIsolation: true` + `nodeIntegration: false`，渲染层无法直接访问 Node / 文件系统 / 网络；敏感操作经 `preload.js` 白名单 IPC 由主进程执行。拓扑窗口使用独立的 `topology/preload.js`，只暴露一个"写配置包"能力。
- **凭据加密**：密码与密钥口令使用 Electron `safeStorage`（Windows DPAPI）加密保存，**不写入会话文件**。
- **主密码加密导出**：导出密码用 `scrypt`（N=16384）+ `AES-256-GCM`，salt 随数据走，密码错误 / 数据篡改均无法解密。
- **主机密钥校验**：首次连接显示 SHA-256 指纹并要求人工确认，写入 `known_hosts.json`，防范中间人攻击。
- **严格 CSP**：禁止外部脚本与远程连接，页面仅加载本地资源（G6 已本地化，无 CDN 依赖）。
- **输入安全**：动态文本使用 `textContent` 写入，不以 `innerHTML` 拼接用户 / 远程数据；导出文件名在主进程二次校验，防路径穿越。
- **可审计**：已移除第三方引擎内嵌的 `atob` + XOR 混淆加载器（原用于注入收款二维码），产品内无不可审计的混淆代码、无第三方收款信息。

> 明文协议（Telnet / RLOGIN / FTP）凭据可能被网络监听，敏感场景请使用 SSH / SFTP。

## 运行

环境：Node.js ≥ 22.12、Windows x64。

```bash
npm install
npm start
```

测试（7 个套件，全部离线运行）：

```bash
npm test
# test-format / test-telnet / test-features / test-vault / test-kex / test-import / test-smart
```

- **CDP 运行验证（源码版 Electron 与免安装版 exe 各跑一遍）**：在 v2.1 的 21 项基础上，新增会话参数标签页切换与协议联动、串口 / RLOGIN / RDP / 保持活动 / 日志字段的表单往返读写、参数默认值与越界回落、日志目录与免安装模式数据目录断言。

打包免安装版（产物为 `dist\win-unpacked\openshell.exe`，同步到 `dist\openshell-2.2-免安装\` 后压缩为 `openshell-2.2-免安装.zip`）：
