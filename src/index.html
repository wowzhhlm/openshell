设置

本地端口转发

规则保存到本地；连接建立时自动尝试，断开时自动释放。需要目标服务器允许 TCP 转发。

脚本发送

逐行发送到当前终端，不解析执行结果。发送过程中可点击“停止发送”中断。

主密码设置

主密码用于加密导出会话中的密码。只有主密码相同的电脑才能导入并还原密码。主密码本身仅保存校验串，不会明文存储，也无法找回，请牢记。

Linux 命令查询

内置常用 Linux 命令的中文说明、语法、参数与示例，可离线查询。支持按命令名、功能、分类搜索。

下发配置到交换机

从“网络拓扑与配置生成”生成配置后，粘贴到此处，选择已有的 SSH 会话作为目标，一键下发（自动进入 system-view、下发后 save）。请确认会话凭据已保存。
